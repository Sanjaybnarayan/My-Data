# ISO/IEC 27001 Information Security Management

**Not a compliance claim, and certification is not sought or held.** An
applicability review by a programmer. Legal review required. See
[MASTER_COMPLIANCE_MATRIX.md](MASTER_COMPLIANCE_MATRIX.md).

## Does it apply?

**Not to this application.** 27001 certifies *an organisation's management
system* — a scope statement, a risk treatment plan, internal audit, management
review, an accredited auditor. There is no organisation here to certify.

Some Annex A controls still describe things this code either does or does not
do, and naming them is more useful than dismissing the standard entirely.

## A.8.24 — cryptography

AES-256-GCM, with the entity, record and field bound into the encryption so a
ciphertext moved from one field to another does not decrypt. One data key,
wrapped separately by a PIN-derived key, a WebAuthn credential and a recovery
phrase, and optionally escrowed to the household's Drive.

`docs/SECURITY.md` covers the scheme. `docs/SEALED_VALUES.md` covers what
happens when a sealed value reaches a screen that cannot read it — it is named
as unreadable rather than shown blank, because a blank looks like an empty
field.

## A.5.15 — access control

Enforced in `js/data/repository.js`, not in the interface. Every read and write
calls `assertCan`, so a screen never gets the chance to forget. Five roles, and
a child may write nothing at all. The server enforces it too:
`apps-script/Policy.gs` is generated from the schema and covers all
47<!--live:entities--> entities,
so the rules cannot drift between client and backend.

## A.8.15 — logging

Covered in [ELECTRONIC_RECORDS.md](ELECTRONIC_RECORDS.md), including the gap:
the log is not tamper-evident.

## A.5.30 — continuity, and why it is only `DESIGNED`

Key escrow exists and a recovery phrase exists, so a household that loses a
device is not locked out of its own records. What does not exist is a **tested
restore**. Nothing takes a backup, wipes a database and puts it back, and there
is no `BACKUP.md` or `RECOVERY.md` — both are on the missing-documents list in
`docs/PHASE_AUDIT_0_13.md`.

Continuity that has never been exercised is a plan, not a capability. Calling it
`IMPLEMENTED` would be the kind of small overstatement this whole review exists
to avoid.
